## 三、如何继续补充图片

1. 将新图片放入对应目录：
   - 景点 → `assets/photos/<景点id>/`
   - 文化名片 → `assets/culture/<文化id>/`
   - 美食 → `assets/food/<美食id>/`

   文件名建议为 `01.jpg`、`02.jpg`…
2. 运行根目录下的 `build_photos.js`（Node 环境）：
   ```bash
   node build_photos.js
   ```
3. 该脚本会自动扫描目录并重新生成 `js/photos.js`，网站刷新后即可生效。
